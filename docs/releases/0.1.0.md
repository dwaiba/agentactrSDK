Initial public preview release.

Highlights:
- Rust CLI for provider-neutral coding-agent orchestration.
- Default Codex, GitHub, Git, Docker, and local artifact integrations.
- Run-scoped artifacts, trace/debug bundles, quality gates, and issue workflows.
- Native CLI archives for Linux x86_64, Linux arm64, and Apple Silicon macOS.
- Docker runtime and static CLI images for linux/arm64.
- Secure-by-default lifecycle, manifest, and replay/audit hardening.

Operational notes:
- Automatic tracker finalization remains review-gated unless explicitly configured.
- Docker images are linux/arm64 and include SBOM/provenance attestations.
- GHCR may show an `unknown/unknown` manifest entry for each image; that entry is the attached attestation manifest, not a second runnable platform.
